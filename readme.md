# 👋 Welcome

Halo! Selamat datang di repository portofolio saya.

Repository ini merupakan dokumentasi perjalanan belajar, hasil praktik, serta proyek yang saya kerjakan selama mengikuti **Program Praktik Kerja Lapangan (PKL) Data Analytics** di **PT Edusoft Center Teknologi**.

Seluruh materi, latihan, studi kasus, hingga proyek yang terdapat pada repository ini disusun sebagai bentuk pengembangan kompetensi di bidang **Data Analytics**, mulai dari proses pengumpulan data, pembersihan data, analisis, hingga penyajian insight dalam bentuk visualisasi yang mudah dipahami.

Selain kemampuan teknis, program ini juga membentuk kemampuan berpikir analitis, problem solving, dokumentasi pekerjaan, penggunaan Git & GitHub, serta budaya kerja profesional di industri.
